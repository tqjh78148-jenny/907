# 新北市立頭前國民中學 - 定期評量成績查詢與管理系統

專為**頭前國中**設計之段考成績公布、查詢與導師登錄系統。支援學生家長快速查詢段考成績、與前次段考進行全方位比對分析，並提供導師極速依序登錄成績、自動算分、即時排名與 Excel 匯入匯出功能。

> 📢 **【系統定位與重要提醒】**
> 本平台為導師即時提供家長掌握學生學習進退步之專區，學生各項**最後正式成績與學期評量紀錄，仍一律以「新北市校務行政系統」為主**。

---

## 🌟 系統亮點特色

### 1. 🎓 學生 / 家長成績查詢專區
- **多重安全查驗**：輸入「班級、座號、學生姓名、身分證末三碼」進行身分核對，保護學生個人隱私。
- **支援科目分批輸入與學校排名延遲公布**：
  - 若部分學科仍在閱卷登錄中，或教務處全校排名尚未公布，家長**依然可以順暢查閱已公布科目**與歷史成績對照。
  - 尚未輸入之科目友善標示「待任課教師登錄」，全校排名標示「學校尚未公布」，系統絕不會報錯或誤判為 0 分。
- **段考進退步全對比**：
  - 本次段考（907班 115學年度第1學期第1次段考）與上次段考（807班 114學年度第2學期第3次段考）並列比較。
  - 清楚列出國文、英語、數學、社會、自然、總分、平均、班名次、年名次之**增減消長**（🔺 進步 / 🔻 退步）。
  - 對照全班各科平均，了解學科優勢與待加強科目。
- **可視化圖表分析**：
  - **五科能力平衡雷達圖**（本次 vs 上次 vs 班平均），清楚掌握學習雷達。
  - **學科成績柱狀對照圖**。
- **導師溫馨評語與會考衝刺建議**：依據學生表現與進步幅度智慧給予教育激勵。
- **一鍵列印成績單**：格式符合 A4 紙張與正式通知單排版，包含簽章欄位，可直接列印或另存為 PDF。

### 2. 👩‍🏫 導師成績管理與依序輸入專區
- **專屬登入身分驗證**：專屬帳號「**907導師**」、密碼「**123456789**」，登入後方可解鎖全班成績輸入、修改與 Excel 匯出匯入功能，防止未授權更動。
- **極速連打輸入設計（Sequential Entry）**：
  - 完整載入 907 班全班 31 位同學名冊與座號。
  - 鍵盤快捷鍵支援：在成績欄位輸入分數後按 **Enter** 或 **Tab** 自動跳下一科；打完自然科按 **Enter** 自動跳到下一位同學國文！
- **即時自動計算（Real-time Calculation）**：
  - 輸入或修改任一科分數，系統毫秒級即時更新**總分**、**平均**與**進退步**（自動比對 807 班前次總分）。
  - 支援「一鍵重新計算全班排名」（依照總分高低自動排列第 1 至 31 名）。
- **Excel 匯出與匯入（相容 807 欄位規範）**：
  - 📤 **一鍵匯出 907 班成績總表 Excel (.xlsx)**：欄位完全對齊 `班級 | 學號 | 座號 | 姓名 | 國文 | 英語 | 數學 | 社會 | 自然 | 總分 | 平均 | 班名次 | 年名次 | 進退步`，並自動產生底部各科平均行。
  - 📥 **一鍵匯入 Excel / CSV**：支援學校現有批次成績檔直接匯入。
  - 💾 **本地資料保存**：成績可隨時儲存於瀏覽器 LocalStorage，免去資料遺失煩惱。

### 3. 📊 全班表現統計分析專區
- 全班受試人數、班平均總分、五科總平均、最高總分。
- 五科各科平均與及格率（>=60分比例）統計表。
- 成績級距分布圓環圖（90分以上、80~89、70~79、60~69、不及格）。
- 🌟 **「進步之星」前五名榮譽榜**：表揚總分進步最多之優秀同學。

## 🚀 快速啟動方式

本系統具備**零依賴性**，支援以下多種開啟方式：

### 方法一：雙擊捷徑啟動（最推薦）
直接滑鼠連點兩下目錄下的 **`啟動系統.bat`**，系統將自動啟動本地伺服器並為您開啟預設瀏覽器！

### 方法二：直接點開網頁（離線可用）
滑鼠連點兩下 **`index.html`**，即可直接在 Chrome、Edge 或任何瀏覽器中正常運作，無需連網或安裝伺服器。

### 方法三：透過 Python 啟動伺服器
在終端機執行：
```bash
python run_server.py
```
瀏覽器將自動開啟：`http://localhost:8080/index.html`
